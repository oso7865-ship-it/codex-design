## 1. 작업 요약

- 320px 고객 화면과 768px 관리자 태블릿 화면의 페이지 가로 넘침을 제거했다.
- 비회원 첫 방문에 체험 종료 Bottom Sheet가 자동 노출되지 않도록 사용자 조건을 추가했다.
- 모바일 플랜 화면에서 플랜 카드를 이용 방식 설명보다 먼저 배치하고 제목의 강제 줄바꿈을 제거했다.
- Family 플랜 상세 화면을 기존 상세 컴포넌트 재사용 방식으로 추가했다.
- 고객 헤더와 마이페이지의 공개 관리자 진입 링크를 제거했다.
- 푸터와 상세 페이지의 “필요한 정보” 개발 문구를 사용자용 안내로 바꾸고 실제 목적지와 연결했다.
- 관리자 인증·접근 거부·세션 만료, 고객·관리자 알림, 계정 설정, 결제수단 등록, 고객지원, 약관, 404·서비스 오류 화면을 추가했다.
- 활성 구독이 없는 경우를 기존 `EmptyState` 컴포넌트로 처리했다.
- 터치 영역, 색상 대비, 키보드 포커스와 모션 감소 설정을 보완했다.
